# 构建说明

## 用户不需要编译

成品已经位于：

`release\d3d9.dll`

## 源码

`source\src\d3d9_proxy.cpp`

源码不依赖 Windows SDK 头文件、MSVC CRT 或 MinGW Runtime。

所有必须的 Win32 ABI 类型在源码内定义，Windows API 在运行时解析。

## 构建工具

开发侧使用：

- Clang 17
- LLD 17
- target：`i686-pc-windows-msvc`

核心参数：

```text
-O2
-ffreestanding
-fno-exceptions
-fno-rtti
-fno-stack-protector
-fno-builtin
```

链接：

```text
/dll
/machine:x86
/nodefaultlib
/entry:DllMain
/subsystem:windows,6.0
/dynamicbase
/nxcompat
/Brepro
```

完整一键脚本：

`source\build.bat`

BAT 使用 UTF-8+CRLF，并执行 `chcp 65001 >nul`。
