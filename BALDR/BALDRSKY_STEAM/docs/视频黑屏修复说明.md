# 视频黑屏修复说明

## 现象

BALDR SKY 的老式视频播放在现代 Windows 上可能出现：

- 有声音；
- 视频区域黑屏；
- 尤其重复播放 OP/ED 时容易出现。

用户长期实机经验确认：

`HKEY_CURRENT_USER\Software\Microsoft\Direct3D\Shims\EnableOverlays`

当前 `BaldrSky.exe` 完整路径对应 DWORD 为 `0` 时可正常播放。

---

## 兼容层实现

默认：

```ini
[Compatibility]
EnableVideoOverlayFix=1
```

兼容层只打开：

`HKCU\Software\Microsoft\Direct3D\Shims\EnableOverlays`

并以当前主程序**完整路径**作为值名。

逻辑：

1. 启动时查询当前值；
2. 不存在或非 0 时写 DWORD 0；
3. 创建轻量守护线程；
4. 按 `OverlayGuardIntervalMs` 查询；
5. 只有再次变成非 0 时才重写；
6. 不操作其他程序对应的值。

只使用 HKCU，不需要管理员。

## 如何关闭

```ini
EnableVideoOverlayFix=0
```

关闭后：

- 不创建/修改该值；
- 不启动 Overlay 守护线程；
- 不删除用户已有值。
