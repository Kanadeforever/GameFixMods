# 视频黑屏修复说明

## 现象

BALDR SKY 的老式视频路径可能出现：

- 声音正常；
- 画面黑屏。

游戏本体使用老式 MCI/DirectShow 风格视频路径。

## 已验证修复

当前 EXE 对应：

```text
HKCU\Software\Microsoft\Direct3D\Shims\EnableOverlays
```

DWORD = 0 后可正常播放。

## test13 起沿用至 test14 的实现

VideoOverlayFix 已经提升为**核心常开功能**，不再提供 `EnableVideoOverlayFix` INI 开关。

兼容层：

- 只处理当前 `BaldrSky.exe` 完整路径；
- 启动时保证值为 0；
- 内部每 500ms 轻量检查一次；
- 只有被改回非 0 才再次写入；
- 不修改其他程序。

英文版 test8 已实机确认该逻辑正确生效。
