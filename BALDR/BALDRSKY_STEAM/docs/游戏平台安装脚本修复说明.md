# Steam 安装脚本兼容修复说明

## 根因

Steam 发行包 `install.vdf` 会向：

```text
HKEY_CURRENT_USER\Software\Microsoft\Windows NT\CurrentVersion\AppCompatFlags\Layers
```

写入当前：

```text
%INSTALLDIR%\BaldrSky.exe = "~ DPIUNAWARE VISTARTM"
```

这会在游戏进程创建前强制 DPI Unaware + Vista 兼容层。

## 当前实现

默认：

```ini
EnableSteamInstallScriptFix=1
```

启动后兼容层静默：

1. 只寻找目标 `AppCompatFlags\Layers` 子块；
2. 只在唯一命中时修改；
3. 第一次修改前保留 `install.vdf.baldrskywin11fix.bak`；
4. 临时文件完整写入后再原子替换正式 VDF；
5. 同时从当前 EXE 的 Layers 字符串中只删除 `DPIUNAWARE` / `VISTARTM`；
6. 其他用户 token 保留；
7. Steam 验证/更新恢复 VDF 后，下次启动会再次静默修复。

正常过程不弹窗、不自动重启游戏。

## install.vdf 缺失

只有整个 `install.vdf` 不存在时才弹 MessageBox：

- 中文游戏：中文提示；
- 英文游戏：英文提示；
- 提醒用户验证 Steam 文件完整性；
- 点击确定后继续游戏，不退出。

## 为什么仍保留开关

这一项会修改 Steam depot 文件和当前用户 AppCompat 注册表，因此保留给高级用户关闭；它与 SteamFix/VideoOverlayFix/PixelBoundaryFix 这三个基础稳定性修复不同。

## test14

ReShade 链式加载与 InstallScriptFix 无耦合；test14 不改变 VDF/注册表净化算法。
