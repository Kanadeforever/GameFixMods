# 外部资料索引

本文件只记录项目使用过的外部公开资料主题，真正的代码结论以包内逆向证据和用户实机日志为准。

## Steam InstallScript

用于确认 Steam InstallScript 的 Registry 行为和启动前执行时序。

## Windows DPI

用于确认 System DPI Aware、DPI virtualization、AppCompat DPI shim 的行为。

## Direct3D Shims / EnableOverlays

用于理解老式视频 Overlay 黑屏 workaround 的系统背景。

## BALDR SKY 社区历史问题

曾用于调查：

- 视频黑屏；
- 启动 Runtime Error；
- 存档/路线崩溃等长期报告。

项目最终只默认修复有代码或实机证据充分的项目。

## test11/test12 字体像素边界问题

该项不依赖外部资料判断根因：

- 中文版 `BaldrSky.bin` 提供静态反汇编证据；
- 用户中文版实机提供 `TargetBase-4` 连续命中和修复后不崩的决定性证据。

## ReShade wrapper chaining

用于 test14 的可选图形后处理链：

- ReShade 6.7.0 起增加 `[PROXY] EnableProxyLibrary / ProxyLibrary`；
- 当前官方版本 6.8.0（2026-08-02）；
- ReShade 单一 DLL 支持多种图形 API，32 位游戏使用 ReShade32.dll。
