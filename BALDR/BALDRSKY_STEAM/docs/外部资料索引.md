# 外部资料索引

本文件只记录调查中实际参考过的外部资料。外部 workaround 不等于项目已经接受的修复方案。

## BALDR SKY 视频黑屏

### Steam 指南：baldr sky op ed问题的处理

`https://steamcommunity.com/sharedfiles/filedetails/?id=2157620908`

用途：确认 BALDR SKY 社区长期使用 `Direct3D\Shims\EnableOverlays` 当前程序值改为 0 解决“视频黑屏只剩声音”。

## Windows / DirectShow EnableOverlays

### Microsoft Q&A：DirectShow setting shims key when UAC prompt appears

`https://learn.microsoft.com/en-us/answers/questions/883009/directshow-setting-shims-key-when-uac-prompt-appea`

用途：确认 DirectShow/EVR 场景中，同一个 `EnableOverlays` 项被系统设置后可以导致视频窗格黑屏。

### VirtualDub2 Ticket #186

`https://sourceforge.net/p/vdfiltermod/tickets/186/`

用途：确认该项可能再次被系统改回 1；设为 0 是实际可用 workaround，因此 test8 增加轻量守护有现实依据。

## Windows 11 启动 workaround

### Steam 指南：Crashing on startup fix for windows 11

`https://steamcommunity.com/sharedfiles/filedetails/?id=3437455607`

用途：了解社区常见的 Win7 兼容模式、管理员、禁用全屏优化、60Hz、128MB Cache、DEP 等 workaround。

项目没有把这些项目全部照单全收；通过 DMP/运行时 Probe 已经找到更具体的 Steam `.patch` 根因。

### Steam 讨论：Game Cannot Launch

`https://steamcommunity.com/app/741140/discussions/0/3121535825782012357/`

用途：了解 Nahimic、VC++ x86 Runtime、DXVK 等社区个案。

其中 Nahimic/60Hz/128MB/DEP 当前都没有达到项目“默认自动修改”的证据门槛。


## 32 位 / LAA 背景

### PCGamingWiki：Baldr Sky

`https://www.pcgamingwiki.com/wiki/Baldr_Sky`

用途：记录该游戏为 32 位 D3D9 程序，并有 LAA 相关社区提示。项目已经实际检查中英文 EXE 的 LAA 标志，但当前没有内存耗尽故障证据，因此没有把 LAA 变成默认修改。

## v0.1-test9 范围收敛说明

截至 test9，外部资料只继续作为历史背景和排查索引。

用户已决定：没有实际复现的老中文版/英文版问题不再主动扩展修复。

因此社区中的存档、Nahimic、DEP、60Hz、Image Cache 等 workaround 不会仅凭传闻自动写入兼容层；以后中文版若真实遇到，再按具体证据处理。
