# 崩溃监视器工具说明

## 位置

```text
release\tools\crash_monitor
source\tools\crash_monitor
```

这是项目早期用于主动调试、抓取异常和生成 DMP 的稳定辅助工具，不是正常游戏运行依赖。

## test13 起沿用至 test14 的日志/诊断策略

默认：

```ini
EnableLog=0
LogLevel=3
EnableCrashDiagnostics=1
```

正常玩家默认不生成日志，也不会只为了普通诊断额外安装 VEH/VCH。

遇到问题时，小白通常只需要把：

```ini
EnableLog=1
```

即可得到最高 `LogLevel=3` 与完整普通 AV 现场。

## 与 PixelBoundaryFix 的关系

PixelBoundaryFix 正常模式是异常发生前的内联检查，不依赖 VEH/VCH。

如果内联补丁安装失败，兼容层会自动启用 test11 已实机验证的精确异常恢复；这个安全回退与 `EnableLog` / `EnableCrashDiagnostics` 解耦，因此不能被用户误关。

只有出现新的、不能由兼容层日志说明的最终崩溃时，再同时使用 CrashMonitor 获取完整 DMP。
