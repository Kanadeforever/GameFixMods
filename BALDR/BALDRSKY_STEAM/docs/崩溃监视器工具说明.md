# 崩溃监视器工具说明

## 位置

用户工具：

`release\tools\crash_monitor`

源码：

`source\tools\crash_monitor\BaldrSkyCrashMonitor.py`

## 用途

这是本项目早期制作并实际成功取得过有效 DMP 的 Python 调试监视器。

可以：

- 等待 `BaldrSky.exe`；
- 使用 Windows Debug API 附加；
- 记录异常代码和 x86/WOW64 寄存器；
- 读取栈；
- 主动保存 MiniDump。

## 当前使用原则

`v0.1-test9` 已经进入兼容层正式候选阶段，内置：

```ini
EnableCrashDiagnostics=0
```

默认关闭轻量 VEH/VCH。

原因是 test8 已观察到一些程序自身能够处理的 first-chance 异常；长期默认记录会把“可恢复内部异常”误看成“真实崩溃”。

以后如果用户真正再次遇到退出：

1. 先把 `EnableCrashDiagnostics=1`；
2. 若 `d3d9.log` 仍不足；
3. 再运行本 CrashMonitor 获取完整调试事件/DMP。

工具继续随包保留，方便任何单包独立接档。
