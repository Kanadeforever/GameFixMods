# 字体像素边界扫描工具说明

## 位置

```text
release\tools\pixel_boundary_scanner\pixel_boundary_scanner.py
source\tools\pixel_boundary_scanner\pixel_boundary_scanner.py
```

## 用途

对明文核心 `BaldrSky.bin` 离线验证 PixelBoundaryFix 的完整结构是否唯一：

- 像素混合核心；
- 故障读取；
- 目标对象栈来源；
- 安全续接点。

## 使用

```text
python pixel_boundary_scanner.py BaldrSky.bin
```

中文版当前结果：

```text
内联补丁点：0x006C1B98
故障读取点：0x006C1B9B
正常返回点：0x006C1B9D
越界像素续接：0x006C1C14
目标对象栈偏移：0x38
结果：PASS
```

运行时 DLL 仍会重新扫描当前已解包主映像，不直接依赖这些固定地址。
