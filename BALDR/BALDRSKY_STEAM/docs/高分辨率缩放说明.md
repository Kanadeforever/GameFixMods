# 高 DPI 缩放说明

## 目标

BALDR SKY 是 2009 年固定像素 UI。现代 Windows 对 DPI Unaware 程序进行传统 DPI 虚拟化时，800×600 窗口可能被放大成约 1000×750 等逻辑尺寸。

## 实现

默认：

```ini
EnableHighDpiFix=1
```

把进程设置为 **System DPI Aware**，关闭传统 DPI 虚拟化。

故意不使用 Per-Monitor V2，因为游戏没有针对 `WM_DPICHANGED` / 跨显示器 DPI 动态切换设计。

## Steam 干扰

原 Steam `install.vdf` 会强制：

```text
~ DPIUNAWARE VISTARTM
```

这会在进程创建前覆盖我们的 DPI 意图。

因此默认同时启用 InstallScriptFix，从源头静默删除该 AppCompat 子块。

用户已经实机确认：处理 VDF 后 Steam 不再重新写回兼容/DPI设置，窗口恢复预期 800×600，System DPI Aware 日志成功。

## 为什么 HighDpiFix 仍保留开关

它属于明显可见的窗口/DPI行为，少数特殊多屏或兼容环境可能希望保持系统默认，因此仍允许高级用户关闭。SteamFix、VideoOverlayFix、PixelBoundaryFix 则属于基础稳定性问题，test13 起不再提供关闭开关。

## test14

ReShade 链式加载不改变 DPI/InstallScript 修复顺序；高 DPI 仍在 D3D9/ReShade 后端真正加载之前初始化。
