# BALDR SKY Steam Windows 10/11 兼容层 v0.1-test14 使用说明

## 1. 功能

本兼容层以 Win32/x86 `d3d9.dll` 形式加载，当前核心功能为：

- 修复 Steam 移植代码导致的启动 `0xC0000005`；
- 静默处理 Steam `install.vdf` 强制写入的 `~ DPIUNAWARE VISTARTM`；
- 修复老式视频“有声音但黑屏”；
- 默认启用 System DPI Aware；
- 支持 Windows 原生 D3D9 与 DXVK x32；
- 修复字体/像素混合目标缓冲区左边界前溢 1 个 32bpp 像素导致的高频崩溃。

其中以下三项已经被提升为**核心常开功能，不再提供 INI 关闭开关**：

1. SteamFix；
2. VideoOverlayFix；
3. PixelBoundaryFix。

## 2. 安装

把 `release` 中：

```text
d3d9.dll
d3d9.ini
```

放到 `BaldrSky.exe` 同目录即可。

也可以运行：

```text
release\deploy_test14.bat
```

普通用户不需要编译源码。

## 3. DXVK

默认：

```ini
[Graphics]
Backend=0
EnableReShade=0
```

含义：

- 同目录存在可加载的 `d3d9_backend.dll`：优先使用它；
- 不存在：自动加载 Windows 系统 32 位 D3D9。

使用 DXVK 时，把 **x86/32 位 DXVK 的 `d3d9.dll`** 改名为：

```text
d3d9_backend.dll
```

不要覆盖兼容层自己的 `d3d9.dll`。

## 4. ReShade

ReShade 是独立于 `Backend` 的可选中间层。

默认关闭：

```ini
[Graphics]
EnableReShade=0
```

启用时：

1. 使用 ReShade 6.7 或更新版本的 **32 位** DLL；
2. 将它命名为 `ReShade32.dll`，与 `BaldrSky.exe` 放在同一目录；
3. 把 `EnableReShade=1`。

调用链：

```text
BaldrSky.exe
  -> d3d9.dll            本兼容层
  -> ReShade32.dll       可选 ReShade
  -> d3d9_backend.dll    如果 Backend 选择到自定义后端，例如 DXVK
     或 Windows 系统 d3d9.dll
```

兼容层会在加载 ReShade 前，只更新 `ReShade.ini` 中：

```ini
[PROXY]
EnableProxyLibrary=1
ProxyLibrary=<最终后端绝对路径>
```

其他 ReShade 配置不会被重写。`ReShade32.dll` 缺失或加载失败时，游戏会安全回退到普通 D3D9 后端。

## 5. 默认 INI

test14 的发布配置为：

```ini
[Compatibility]
EnableSteamInstallScriptFix=1
EnableHighDpiFix=1

[Graphics]
Backend=0
EnableReShade=0

[Diagnostics]
EnableLog=0
LogLevel=3
EnableCrashDiagnostics=1
```

### 日志原则

默认 `EnableLog=0`，因此正常玩家不会生成 `d3d9.log`。

如果遇到问题，只需改：

```ini
EnableLog=1
```

即可。`LogLevel=3` 与 `EnableCrashDiagnostics=1` 已经预设好，会直接给出最详细日志和普通 AV 现场，不需要小白再理解第二组诊断选项。

### PixelBoundaryFix 安全回退

PixelBoundaryFix 正常使用异常发生前的内联边界检查，不依赖 VEH/VCH。

如果内联补丁因为极端环境无法安装，兼容层会自动启用 test11 已实机验证的精确异常恢复。这个安全回退**不受 EnableLog 和 EnableCrashDiagnostics 影响**。

## 6. Steam InstallScript

Steam 原 `install.vdf` 会写入：

```text
~ DPIUNAWARE VISTARTM
```

兼容层默认会静默删除对应的 `AppCompatFlags\Layers` 子块，并清理当前 EXE 注册表值中的这两个 token。

- 已经修过时零操作；
- Steam 更新/验证恢复后，下次启动自动再处理；
- 原始 `install.vdf` 只备份第一次；
- 不自动重启游戏；
- 只有 `install.vdf` 整个缺失时才弹 MessageBox：中文版显示中文、英文版显示英文，提示验证完整性，然后继续游戏。

## 7. PixelBoundaryFix 实机结论

test11 已证明故障现场严格满足：

```text
EDI == TargetBase - 4
```

test12 改为异常发生前内联检查后，用户在原来稳定崩溃的存档/读档界面反复移动鼠标、切换存档槽，**不再崩溃**；内联计数至少达到 326 次。

因此这不是偶发异常，而是正常 UI/字体绘制路径会高频踩中的真实边界错误。
