# 特征码扫描工具说明

## 工具位置

`source\tools\signature_scanner\signature_scanner.py`

## 用途

这是从 test8 开始使用、test9 继续保留的 SteamFix 离线验证工具。

它不会运行游戏，也不会修改 EXE，只读取 `BaldrSky.exe` 并重建 PE 的运行时 RVA 映像，然后执行与 DLL 同一思路的语义扫描。

## 不需要第三方 Python 包

只使用：

- `pathlib`
- `struct`
- `sys`

因此普通 Python 3 即可运行。

## 用法

```text
python signature_scanner.py BaldrSky.exe
```

同时验证多个版本：

```text
python signature_scanner.py BaldrSky_CN.exe BaldrSky_EN.exe
```

## PASS 条件

以下项目全部必须唯一命中：

- `BaldrUtil.dll`
- `InitSteam`
- `CloseSteam`
- `UpdateSteam`
- `ResetAchievements`
- `GetAchievement`
- BaldrUtil LoadLibrary 结构
- GDI32 LoadLibrary 结构
- InitSteam slot
- UpdateSteam slot
- Steam init entry
- UpdateSteam trampoline

并额外要求：

- 两次 LoadLibrary 使用同一 IAT；
- InitSteam/UpdateSteam 使用同一 GetProcAddress helper。

任何一项不满足，最终结果为 FAIL。

## 为什么这个工具必须随包

以后如果 Steam 更新 EXE、出现其他语言版或社区版本，先跑这个工具即可判断是否仍满足当前安全签名。

不要在 FAIL 的 EXE 上强行套固定地址补丁。
