# SteamFix 特征码扫描工具说明

## 位置

```text
release\tools\signature_scanner\signature_scanner.py
source\tools\signature_scanner\signature_scanner.py
```

## 用途

离线验证一个或多个 Steam `BaldrSky.exe` 是否能被当前 SteamFix 语义扫描器安全、唯一定位。

## 使用

```text
python signature_scanner.py BaldrSky.exe
python signature_scanner.py 中文版.exe 英文版.exe
```

只有所有关键结构都唯一匹配时才输出 PASS。

## test13 结论

当前实际中文与英文 Steam EXE 均重新扫描 PASS。报告保存在：

```text
docs\证据\第十三版中英文特征码复核报告.txt
```

SteamFix 与 PixelBoundaryFix 是两套独立扫描逻辑。
