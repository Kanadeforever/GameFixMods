afb81b11704cf22bc572ce39b48b1cd046dca1a47ca220b5df77fd02f9b6a5d8

**原逻辑**：
- 0x401440 调用 0x401390 检查 comap.dat。
- 检查失败后通过 KERNEL32!WinExec 启动 reg.exe。
- 等待并最多重试 10 次；仍失败则返回 0。
- 上层 0x402F50 根据返回值弹出“認証ファイルに異常があります”并阻止启动。

**修改**：
- 文件偏移 `0x1440`（VA 0x401440）
- 原字节：`E8 4B FF FF FF 83`
- 新字节：`B8 01 00 00 00 C3`
- 含义：mov eax,1 / ret

这只让认证包装函数直接返回成功，不修改游戏其余启动流程。
